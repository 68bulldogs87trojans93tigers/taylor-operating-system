# Changelog

## v0.3.5 — Unmissable Notes & Updates

- Renamed the sidebar destination to **Tasks & Notes**.
- Added a prominent Notes & Updates section above the task board.
- Moved the Notes & Updates button directly beneath every task name so it no
  longer depends on horizontal scrolling.
- Kept the latest note or update visible beside its task.

## v0.3.4 — Visible Task Notes Repair

- Made Notes & Updates a dedicated, labeled task-board column.
- Replaced the generic Open button with **Notes & updates**.
- Kept the latest activity summary directly beside each task.
- Added an always-visible v0.3.4 marker in the sidebar.
- Preserved the task detail drawer, team notes, timestamps, automatic field
  history, AI COO activity context, and role/company permissions.

## v0.3.3 — Task Notes & Activity

- Added task notes, authors, timestamps, automatic change history, task editing,
  and recent activity context for AI COO.

## v0.3.2 — Developer Company Manager

- Added company creation, editing, archiving, restoration, and dynamic lists.

## v0.3.1 — Developer Invitations and Permissions

- Added invitations, roles, company access, and revocation.
