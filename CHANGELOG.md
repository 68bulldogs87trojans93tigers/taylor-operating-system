# Changelog

## v0.3.3 — Task Notes & Activity

- Added a task detail drawer with low-click task editing.
- Added team notes with authors and timestamps.
- Added an immutable task activity timeline.
- Automatically records changes to task name, business, owner, due date,
  priority, status, and details.
- Added the latest update beneath each task on the Master Task Board.
- Linked tasks from Business Workspaces and Team Accountability to their detail
  panel.
- Enforced Read Only, Editor, Developer, and company-level permissions on task
  activity through Supabase Row Level Security.
- Added recent task activity to the AI COO context.
- Preserved company management, invitations, sortable tasks, meetings, and the
  mortgage pipeline.

## v0.3.2 — Developer Company Manager

- Added company creation, editing, archiving, and restoration.
- Made company lists dynamic across the application.
- Added database-safe company renaming.

## v0.3.1 — Developer Invitations and Permissions

- Added invitations, role permissions, company access, and revocation.
