# Taylor Operating System

This is a real Next.js application using Supabase.

## Deploy
1. Upload the contents of this folder to the root of the GitHub repository.
2. In Vercel, leave Root Directory blank because package.json is at repository root.
3. Framework Preset: Next.js.
4. Add NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY.
5. Run supabase/setup.sql in Supabase SQL Editor.
6. Redeploy without build cache.
